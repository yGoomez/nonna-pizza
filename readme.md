## Pizzaria Nonna Pizza

O presente projeto consiste no desenvolvimento de um sistema web para uma pizzaria, com o objetivo de facilitar e otimizar o processo de realização e gerenciamento de pedidos.
A plataforma permitirá que os clientes realizem seu cadastro, consultem o cardápio disponível e efetuem pedidos de pizzas de forma prática e intuitiva. Após a realização do pedido, as informações serão encaminhadas diretamente para uma área administrativa destinada ao pizzaiolo ou responsável pela produção.
O sistema também contará com funcionalidades de gerenciamento de pedidos, permitindo o acompanhamento das demandas realizadas por todos os clientes. O administrador terá controle sobre os pedidos recebidos, podendo organizar e acompanhar o processo de produção.
Além disso, será disponibilizada uma área administrativa para o gerenciamento do cardápio, onde será possível alterar preços, cadastrar novos sabores, editar informações das pizzas e manter os produtos sempre atualizados.
Dessa forma, o sistema busca proporcionar maior organização, agilidade e eficiência tanto para os clientes quanto para os responsáveis pela administração e produção da pizzaria.


## Cliente

- Criar uma conta
- Fazer login
- Consultar o cardápio
- Realizar pedidos de pizzas
- Cadastrar e alterar endereço
- Finalizar pedidos
- Acompanhar o status do pedido
- Consultar o histórico de compras


## Admin (Pizzaiolo)

- Fazer login no sistema
- Acessar o cardápio
- Cadastrar novos sabores de pizzas
- Alterar informações das pizzas
- Alterar preços das pizzas
- Visualizar os pedidos realizados pelos clientes
- Organizar e acompanhar os pedidos em produção
- Atualizar os produtos disponíveis no cardápio
